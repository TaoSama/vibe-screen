# HarmonyOS runtime notices

The Vibe Screen HarmonyOS HAP currently contains no third-party runtime
packages. HarmonyOS SDK and Hvigor components are supplied by the developer's
DevEco installation and are not redistributed in the HAP.

TypeScript and JSON5 are development-only tools used by portable repository
checks. They are not compiled into or distributed with the HarmonyOS HAP.

The license for Vibe Screen itself is included as `license.txt` beside this
notice in the HAP raw resources.
